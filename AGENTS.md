# Tests

- Ne jamais lancer de tests sauf si l'utilisateur le demande explicitement.

# Commits

- Ne créer de commit que sur demande explicite de l'utilisateur. Ne jamais prendre l'initiative de faire un commit.

# Langue

- Le code et les commentaires doivent être 100 % en anglais : identifiants, commentaires, messages de log et textes des scripts.
